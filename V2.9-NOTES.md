# Manu Stream Radio V2.9 — message auditeurs

Base : V2.8 validée par Manu. Cette évolution ne repart pas d'une ancienne version.

## Nouveau dans la régie

Un bloc **MESSAGE AUDITEURS** est ajouté dans la zone **OÙ DIFFUSER ?**.

- champ de 240 caractères maximum ;
- bouton **PUBLIER SUR LE SITE + L’APK** ;
- bouton **EFFACER** ;
- compteur de caractères ;
- texte mémorisé localement dans la régie ;
- publication immédiate via le même canal Supabase Realtime que la web radio ;
- message également inclus dans l'événement `radio-state` ;
- tant qu'un message est publié et que la régie reste ouverte, il est renvoyé toutes les 4 secondes pour qu'un nouvel auditeur connecté après la première publication le reçoive aussi ;
- raccourci Ctrl+Entrée / Cmd+Entrée depuis le champ pour publier.

## Côté auditeurs

Le site web public et l'APK Android affichent le même bandeau **MESSAGE DE MANU** juste sous le bloc « À L'ANTENNE ».

L'APK charge la page publique partagée : l'ajout du bandeau côté page est donc automatiquement visible dans l'APK sans avoir besoin de changer le moteur Android natif.

## Conservation

Toutes les fonctions V2.8 sont conservées :

- musique de fond sur Info / Météo ;
- ducking automatique ;
- jingles montés ;
- rotation musicale anti-répétition environ 2 h ;
- planificateur 7J/24H ;
- Streamlabs ;
- web radio ;
- absence de mise à jour automatique.

## Limite du pont actuel

Le message est transmis par Realtime Broadcast. Il est donc disponible tant que la régie est ouverte et le canal connecté. Il n'est pas stocké publiquement dans une base distante permanente ; ce choix évite d'exposer une clé d'écriture privilégiée dans les clients publics.
