# Sécurité

Ne jamais publier dans ce dépôt :

- token Streamlabs Remote Control ;
- clés API ;
- mots de passe ;
- fichiers `.env` locaux ;
- bibliothèque musicale personnelle ;
- enregistrements privés.

Les paramètres sensibles de Manu Stream Radio doivent rester stockés localement sur la machine de diffusion.
