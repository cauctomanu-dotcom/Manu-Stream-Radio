# Manu Stream Radio V2.8 — musique de fond sur Infos / Météo

Base : branche `v2.7-from-v2.6`, elle-même construite directement depuis la V2.6 fournie par Manu.

## Nouveau

L'enregistreur **Info / Météo** permet désormais d'ajouter une petite musique de fond après l'enregistrement de la voix, sans refaire la prise.

- la prise voix brute reste conservée tant que l'utilisateur ne clique pas sur **EFFACER LA PRISE** ;
- choix d'un média classé **Musique** ;
- volume réglable de 2 % à 40 %, valeur par défaut 12 % ;
- ducking automatique optionnel : la musique baisse lorsque la voix est présente et remonte légèrement dans les silences ;
- la musique boucle automatiquement si elle est plus courte que le bulletin ;
- petit fondu d'entrée et de sortie du fond musical ;
- le jingle V2.7 reste positionnable avant / après / avant + après / aucun ;
- changer le jingle, la musique, le volume ou le ducking recalcule simplement l'aperçu à partir de la prise voix intacte.

## Conservation

La logique de rotation musicale intelligente V2.7 est conservée : anti-répétition sur environ 2 heures, ordre mélangé par rotation et fallback uniquement lorsque toutes les alternatives sont récentes.

Aucune mise à jour automatique n'est réintroduite.

## Vérifications

- JavaScript embarqué : syntaxe valide avec Node ;
- EXE V2.8 : nouvelle section PE `.msr28` ;
- assets HTML/CSS/JS de la V2.8 bien pointés vers `.msr28` ;
- contrôles `newsBedTrack`, `newsBedVolume` et `newsBedDuck` présents dans l'interface embarquée ;
- aucun `update.json` dans les assets V2.8 ;
- ZIP de test contient l'EXE V2.8, le README, l'empreinte SHA-256 et le rappel d'absence d'auto-update.

## Limite importante

Une prise non sauvegardée qui existe uniquement dans la mémoire d'une ancienne instance déjà ouverte ne peut pas être transférée lors du redémarrage de l'application. Si une prise vient d'être enregistrée dans la V2.7 et n'est pas encore sauvegardée dans la bibliothèque, il faut la sauvegarder avant de fermer cette instance.
