# Studio Windows V4

Le Studio Windows V4 n’utilise plus `app/web` comme source distante au démarrage. Son interface est embarquée dans l’EXE.

Les anciens fichiers `app/web` V1/V2 ont été supprimés pour éviter qu’un ancien lanceur ou manifeste de mise à jour ne puisse réinjecter une interface obsolète.

La V3.9.25 reste la référence fonctionnelle/visuelle pour les fonctions historiques à conserver.
