PAS À PAS

Mode d'emploi rapide

1

Importer tes sons

Dans Bibliothèque, clique sur + Importer. Ensuite tu peux envoyer un morceau vers le Lecteur A/B, le conducteur ou le cartouchier.

2

Préparer le conducteur

Utilise + Média pour musique/pub/jingle et + Live pour podcast/libre antenne. Les flèches changent l'ordre.

3

Ajouter et traiter les micros

Clique sur + Ajouter un micro, choisis sa source puis ouvre FX / FILTRES : réduction de bruit, gate, EQ, compresseur, de-esser, limiteur, presets et effets vocaux sont réglables micro par micro.

4

Prendre un appel

+ Ajouter un invité → source Application Windows → Choisir WhatsApp / Discord…. Dans le sélecteur Windows/Edge, choisis la fenêtre de l'appel et partage son audio. Si aucune piste audio n'est fournie, bascule la tranche sur Entrée / câble virtuel.

5

Remplir la soundboard

Un pad vide affiche + ASSIGNER. Clique dessus, choisis un son. Un pad rempli se joue d'un clic ; la petite roue dentée permet de le changer.

6

Streamlabs

Ajoute dans Streamlabs une Application Audio Capture ciblant la fenêtre Edge "Manu Stream Radio", puis une Browser Source avec l'URL overlay. Le guide PDF fourni avec l'EXE détaille tout.

7

Auto 24H

Prépare les heures fixes et la rotation musicale, coche Activer l’automation 24H puis clique sur ARMER / APPLIQUER. Laisse l’application et le PC allumés ; les programmes fixes coupent la rotation puis celle-ci reprend automatiquement.

Conseil : fais toujours un test avec REC MASTER et un enregistrement Streamlabs avant un vrai direct.
